## 怎么开始

1. **先读** `02-精简版`（10 分钟）——了解四类操作怎么选、底线有哪 8 条。
2. **把 `.aiflow/` 复制到你项目的根目录**（骨架已清空，只有模板与填写提示；先看其中的 `README.md`）。
3. **填 `baseline/conventions.md`**——尤其第 8 节「合格范例」，填 2~3 个你项目里写得最好的真实路径。这一项决定 AI 生成时的风格对齐。
4. **按 §3.15 决策树**判断手上任务属于哪类（查询/生成/修改/删除），然后只做对应那部分的动作。
5. 需要查细节时翻 `01-完整版`；完整版开头有「AI 导航索引」，按意图反查最快。

## 四份文档的关系

- **完整版**面向 AI：追求完备与可判定，条款语言与系统中立（示例集中在附录 L）。
- **精简版**面向人：只保留核心判断与动作；不得与完整版偏差，冲突时以完整版为准。
- **演示文档**：条款 ↔ 场景对照，每个动作标注对应章节号。
- **模板包**：可直接复制的骨架，字段中立、示例仅参考。

## 三条最要紧的

1. **底线 8 条（§1.7）任何情况都不能砍**——砍了即视为未按本规范执行。
2. **上下文给错了，它会认真地把事做错**——注入前先声明清单（§3.19 / 附录 J）。
3. **能跑脚本判的，别让 AI 判**（B4）。

## 封装成 Skill

`skill/aipsw/` 是本资料包的标准 Agent Skills 封装：`SKILL.md` 给出可执行的操作手册（判级 → 选模式 → 停点 → 底线 → 反模式 → 自检），`references/` 放四份文档与 `.aiflow` 骨架的快照。安装方式见 [`skill/README.md`](skill/README.md)。
