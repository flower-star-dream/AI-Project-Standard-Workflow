## 2. 结论

- **规范层覆盖：8/8 = 100%**。八项能力都能在条款或模板中找到依据（行号见上表）。
- **改造前可执行层覆盖：0/8 = 0%**。有要求、有模板，但没有统一 CLI 命令、判据、机器可读报告和回归测试。
- **改造后可执行层覆盖：8/8 = 100%**。`scripts/aipsw.py` 承载 1 个 init、4 个 gate、2 个 scan；`tests/test_aipsw.py` 用正反 fixture 验证。
- 缺口分级：P0 2 项（冷启动、主动提问）、P1 6 项（术语/目录/契约/重复度/影响面/删除）、P2 0 项（本次未改文档表达）。
- 证据：`python -m unittest discover -s tests -v` → 20 条通过；`python scripts/aipsw.py gate all` → 退出码 0（术语表/契约为空时仅 T1/S0 警告）。

## 3. 边界

工具只做机械判定：反射/SPI 动态引用、外部调用方、数据引用、语义完整性、运行时行为仍需人工确认；不要让"脚本跑过了"代替这两类确认。
